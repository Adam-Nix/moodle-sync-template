Welcome! Let's get you set up - it takes about two minutes. This program downloads your Moodle files to a folder on this computer. To start:
  1. Enter your Moodle address and key in part 1 (the steps to find the key are there), then press Test login.
  2. Check the folder in part 2 is where you want your files.
  3. Pick which courses are this year's in part 3.
  4. Press Save, close this window, then press Download on the main page.
Parts 4 to 6 are optional. You can come back any time with the gear icon at the top.

1. Your Moodle login

To get your key: open your Moodle address in your browser, log in, click your name (top right) → Preferences → Security keys, and copy the one called Moodle mobile web service. It is saved only on this computer and never shown again.

2. Where your files are kept on this computer

Created for you if it doesn't exist. Changing it later doesn't move files you already downloaded.

Make every copy match?

Nothing is deleted. A file missing in one place is copied there from the others, and where a file differs, the most recent edit is copied everywhere. Files you removed on purpose, like duplicates, come back if a copy still has them.
